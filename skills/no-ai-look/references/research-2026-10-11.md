# 去 AI 味调研（2026-10-11）

## OpenClaw 官网实测拆解（openclaw.ai，1440×900，脚本读出的实际样式，Astro 搭建）

**字体（三种，分工明确）**
- 正文和标题：Switzer（Fontshare，400/500/600/700）。正文 16px、行高 1.6；H1 60.8px、600、字距 -0.03em；区块标题约 21.6px/600；卡片标题 16.3px/600。
- 强调：Sentient 衬线斜体，只加载 400，只用在 H1 的一个词上，珊瑚红。
- 标签/按钮/代码：系统等宽（ui-monospace / SF Mono / JetBrains Mono）。区块标签 12.8px、全大写、字距 0.1em、珊瑚红；按钮 13px/600。
- 字号阶梯：0.75 / 0.8125 / 0.875 / 0.9375 / 1.0625 / 1.25 / 1.5 / 2rem，正文附近很密，大标题直接跳到 3.8rem。

**配色（几乎全灰 + 一个强调色）**
- 背景和文字用 Tailwind v4 原生中性灰：背景 `oklch(0.135 0 0)`（约 #0a0a0a），文字 `oklch(0.985 0 0)`，边框 `oklch(0.269 0 0)`；亮色主题底 98.5%、表面 97%、边框 92.2%、弱化文字 55.5%。AI 味不来自 Tailwind 的灰。
- 珊瑚红：深色 `#f5654a` / `#e05540` / `#b23a28`；亮色 `#d84a31` / `#c24028` / `#9c3222`。
- 第二色海青：深色 `#4fc8ae` / `#2fa48d`，亮色 `#14806e`，用得极少。
- ink `#101012`–`#202024`，paper `#f6f5f3` / `#eceae6`。
- 没有渐变、毛玻璃、发光光斑；唯一光晕是 logo 背后 22% 透明的珊瑚色。阴影 token 三档，首页基本不用。

**版式**
- 内容最宽 75rem，正文 48rem；两侧 1px 竖线贯穿到底，像图纸边框。
- 细线网格：网格背景设成边框色，格间留 1px，格子填回页面底色，不用逐张描边和阴影。
- 圆角分层：小元素 4px、控件 8px、大容器 12/16px、网格单元 0。间距 4px 基数：4/8/12/16/24/32/48/64。

**节奏**：字符画 hero → 安装区（Apps / 一行命令 / npm 页签，三平台下载，具体版本号）→ 两行慢速滚动真推文 → 最新文章 → 功能 3×2 细线网格 → 集成 → 用户作品 → 媒体报道 → 社区 → 订阅 → 谁在背后和资助方。区块之间只用细线分隔。

**图形和动效**：hero 是 11px 等宽珊瑚红、65% 透明的字符画（静态），中间 3D 小龙虾吉祥物。会动的只有推文滚动（161 秒一圈）。悬停：卡片只换背景色；推文头像默认灰度、悬停变彩色；代码行悬停才露出复制按钮。17 条 `prefers-reduced-motion` 规则。动效 0.16s / 0.2s，缓动 `cubic-bezier(.23,1,.32,1)`。

**文案**：口语、带态度、信息具体（「OPEN SOURCE · RUNS ON YOUR MACHINE · NOBODY'S BUSINESS MODEL」「No subscription. No hosted tier.」），有自嘲，交代资金来源和遥测；没有营销空话。

**刻意没做**：紫蓝渐变、渐变文字、光斑、毛玻璃、emoji 图标、彩色竖条、卡片套卡片、跳动统计条、无法核实的数字、三档价格表、区块进场淡入、AI 生成人像。
