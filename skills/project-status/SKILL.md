# 项目全貌与查找

这是只读技能。项目别名、报告位置和展示偏好来自用户层或 agentq 配置，不写死个人映射。

## 看全貌

扫描 `${AGENTQ_PROJECTS_ROOT:-$HOME/projects}` 下主目录为 Git 仓库的项目，每个项目列：

```text
项目名（目录）— 最近提交日期和摘要 · 待做 N · 待决定 N · 远程地址（如有）
```

数据来源：

- `git log -1`
- `docs/BACKLOG.md` 各节未完成条目
- `git remote -v`（只读，不据此推断写权限）
- `agentq status`
- agentq 配置的本地日报/任务汇总

逐条列出真正等待用户决定的条目；带前置条件且尚未满足的单列为“等待条件”，不算当前要用户决定。标出长时间无提交的项目，但不擅自归档。

## 找东西

- 历史会话：仅在用户明确要求查会话时使用宿主提供的会话列表/搜索能力；不要为了日常状态汇总读取原始会话正文。
- 项目目录：返回准确路径。
- 文件、方案、规则：搜索项目 `docs/specs/`、`docs/research/`、`DECISIONS.md`、`AGENTS.md` 等实际存在的文件，给出路径和直接相关摘要。

先给结论和阻断项，再给证据。未读取、未运行或无法访问的来源明确写“未核实”。
