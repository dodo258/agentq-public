# Changelog / 更新日志

## 0.1.0 - 2026-10-13

### English
1. **Complete installation:** install the scheduler, workflow skills, support files and templates through one entry point on macOS.
2. **Background development:** send BACKLOG tasks through Claude CLI, with independent review, local reports and optional Telegram communication.
3. **Safe maintenance:** preserve user configuration and recover complete installation generations through rollback, removal and restore.
4. **Clear scope:** this initial public version supports Claude on macOS; Codex, Linux/WSL and native Windows are not supported in this release.

### 简体中文
1. **完整安装：** 在 macOS 上通过同一个入口安装调度器、工作流技能、支持文件和模板。
2. **后台开发：** 通过 Claude CLI 执行 BACKLOG 任务，提供独立审查、本地报告和可选 Telegram 沟通。
3. **安全维护：** 保留用户配置，通过回滚、卸载和恢复维护完整安装代。
4. **明确范围：** 首次公开版本支持 macOS 上的 Claude；此版本不支持 Codex、Linux/WSL 或原生 Windows。
